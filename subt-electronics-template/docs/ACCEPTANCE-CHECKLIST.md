# Client acceptance checklist

## Content
- [ ] Client legal/business name confirmed.
- [ ] Approved logo, brand colours, typography, and image rights received.
- [ ] Phone, WhatsApp, email, physical address, and opening hours verified.
- [ ] Product names, SKUs, specifications, prices, images, warranty, and publication status approved.
- [ ] Manual stock workflow and verification cadence agreed.
- [ ] Delivery zones, fees, timelines, returns, and warranty policies approved.
- [ ] Privacy notice, terms, and enquiry retention approved.

## Functionality
- [ ] Catalogue/category/product routes verified.
- [ ] Search/filter behaviour implemented and tested.
- [ ] Enquiry persistence, confirmation, notification, spam control, and admin queue tested.
- [ ] Admin invitation and sign-in flow tested.
- [ ] Product, price, inventory, and enquiry status mutations have server-side role checks.
- [ ] Audit events generated for sensitive changes.
- [ ] Empty/loading/success/error/permission-denied states reviewed.

## Quality and operations
- [ ] Responsive checks on small phones/tablets/desktop.
- [ ] Keyboard and screen-reader checks.
- [ ] Metadata, canonical URL, sitemap, robots, and social preview checked for production.
- [ ] Automated tests, dependency scan, and security review passed.
- [ ] Migration and rollback rehearsal completed.
- [ ] Backup and restore tested.
- [ ] Monitoring, support owner, and rollback plan recorded.
- [ ] Client acceptance recorded before public launch.
